# Root Styles Directory

This folder is the new root-level styling layer for the app.

Recommended structure:
- `base/` — base reset and typography rules
- `components/` — shared reusable component styles
- `themes/` — design system variables and theme files
- `utilities/` — helper classes, spacing, layout utilities

Use this as the starting point for migrating from scattered per-page CSS to a central theme and reusable style system.
